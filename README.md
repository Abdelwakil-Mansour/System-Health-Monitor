# System Health Monitor

A Bash-based tool to monitor system health, including CPU usage, memory consumption, disk space, and running processes. This script helps you keep track of your system's performance and resource usage in real-time.

## Features

- Displays CPU, memory, and disk usage
- Lists top running processes
- Simple and easy-to-use Bash script
- Customizable monitoring intervals

## Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/System-Health-Monitor.git
    cd System-Health-Monitor
    ```

2. **Make the script executable:**
    ```bash
    chmod +x system_health_monitor.sh
    ```

3. **Run the script:**
    ```bash
    ./system_health_monitor.sh
    ```
